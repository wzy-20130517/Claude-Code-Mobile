# QQ 桥

## 这是什么

一个把 **QQ 消息**接进这个 CLI 的桥接层。配好之后：

- 你在 QQ 里私聊机器人 → 消息进入对话，等同于在终端输入
- Agent 的回复 → 自动发回 QQ（按轮次分条，超长自动转图片）
- 你不在终端前也能指挥 Agent 干活

**入口是 QQ 私聊，不是群**（群消息默认不唤醒，见下）。

## 快速配置

```bash
/qq setup      # 向导：一次配完（主人号 / 端口 / NapCat API 地址）
/qq on         # 开始监听
/qq status     # 看当前配置和运行状态
```

配完必须 **`/qq off` 再 `/qq on`**（或 Ctrl+X 重启）才真正开始监听 —— 改端口不会自动重连。

## 完整命令

| 命令 | 作用 |
|---|---|
| `/qq` | 看状态（监听中？端口？主人号？） |
| `/qq on` / `/qq off` | 开关监听 |
| `/qq setup` | 交互向导，一次配完 |
| `/qq owner <QQ号>` | 设主人号（只有这个号的私聊会进对话） |
| `/qq port <端口>` | 改监听端口（默认 3000） |
| `/qq api <URL>` | 改 NapCat API 地址（默认 `http://127.0.0.1:5700`） |
| `/qq queue` | 看/删排队消息（Agent 忙时消息会排队） |
| `/qq interrupt on\|off` | 全局打断开关 |
| `/qq open on\|off` | 放行模式（见下） |

配置存 `~/.claude-code-mobile/qq-config.json`，重启保留。

## 消息怎么进来

三条路径：

| 来源 | 行为 |
|---|---|
| **主人私聊** | 进对话，回复发回私聊 |
| **主人在群 @ 机器人** | 进对话，回复发到**那个群** |
| **其他人的群消息** | 不打扰，但**缓存最近 60 条**（Agent 可用 `QQRecall` 工具主动回溯） |

**放行模式**（`/qq open on`）：开启后群内**任何人** @ 都能唤醒。风险是把手机操作权限开放给全群 —— 发现可疑消息 Agent 会自己关掉。

## 消息怎么出去

**自动回复**：Agent 每轮回复自动发回（按 turn 分条，超长转图片，key/token 自动打码）。

**主动推送**：Agent 用 `QQPush` 工具 —— **只能发给主人号**（不接受目标参数，防止被诱导给别人发东西）：

```
QQPush({ text: "..." })                    # 发文本
QQPush({ text: "...", as_image: true })    # 强制转图片（表格/代码用）
QQPush({ path: "/path/to/file.png" })      # 发图片或文件
```

**用户明确要求时才用**（「把这张图发我 QQ」）——不做进度播报，终端里能看到正文。

## QQ 侧的控制词

在 QQ 里发这些词会被桥**拦下当命令**，不会喂给 Agent：

| 词 | 作用 |
|---|---|
| 停 / 停止 / 打断 / stop / abort | 立刻中止当前任务并挂起队列 |
| 继续 / go | 放行队列 |

在 QQ 里发 `/` 开头的命令会**真的执行**，结果转成图片发回。

## 收到什么内容

| 类型 | 处理 |
|---|---|
| 文字 | 直接进对话 |
| **图片** | 下载到 `~/.claude-code-mobile/qq-images/`，作为多模态注入（Agent 能看见） |
| **文件** | 下载到 `~/.claude-code-mobile/qq-files/`，给出本地路径，Agent 用 Read/Bash 自己看 |
| 文件夹 | ✗ QQ 不支持发文件夹，需要先打包 zip |

## 排查

| 现象 | 原因 |
|---|---|
| QQ 发消息没反应 | `/qq` 看是否在监听；改过端口要 `/qq off` + `/qq on` |
| 只有主人的消息有反应 | 正常。群消息默认不唤醒，除非 @ 或开了 `/qq open` |
| NapCat 连不上 | `/qq api` 确认地址；NapCat 本身要跑起来 |
| 回复没发回去 | `/qq status` 看端口；检查 NapCat 是否在线 |

## Agent 自己该知道的

- **群消息不会自动进对话** —— 用户说「群里刚才有人发了个 X」时，用 `QQRecall` 工具回溯
- **你的正文输出 QQ 用户能看见**（自动发回），但**工具调用过程不会**
- **不要用 QQPush 做进度播报** —— 那是给「用户明确要求」用的
- 处理图片/文件时，本地路径已经给好了，**别再去问用户要**
