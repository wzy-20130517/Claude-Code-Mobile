# tests/ —— 临时测试目录

按需写临时测试 / 探测脚本（任意名字，如 `probe-xxx.mjs`），用法：

```bash
node tests/你的脚本.mjs
```

约定：

- **跑完即清**：脚本用完立刻删，别攒着。这里不是回归测试套。
- 脚本不进版本控制（`.gitignore` 已忽略 `tests/*.mjs`），所以也不会被自动提交进来。
- 旧的一整套回归测试（69 个文件）已整体删除，**不要恢复**；
  确实想看历史可以用 `git log -- tests/` 翻。
- 常规验证手段：`node --check <文件>` + `/check`（重启预检）+ 本目录的临时脚本。
